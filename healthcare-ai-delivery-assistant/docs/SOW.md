# Illustrative Statement of Work · NOT AN EXECUTED CONTRACT

## Objective
Demonstrate an evidence-grounded literature research MVP using public documents.

## Deliverables
1. Working local upload/retrieval interface.
2. Optional LLM-generated synthesis with citation instructions.
3. Synthetic-corpus MCP search integration.
4. Test suite, product documentation, and measurement plan.

## Assumptions
Client supplies public or properly licensed documents only; no PHI. API subscription and hosting costs are client-owned if used. Pilot participants are hypothetical until recruited.

## Exclusions
Clinical decision support, compliance certification, enterprise SSO, production support, and guaranteed answer accuracy.

## Acceptance gates
- Gate A: app runs locally from README instructions.
- Gate B: at least 7 automated tests pass.
- Gate C: reviewer can retrieve cited chunks from demo notes.
- Gate D: risks and limitations acknowledged by sponsor.

## Change control
New requirements require documented impact on cost, timeline, risk, and acceptance criteria before prioritization.
